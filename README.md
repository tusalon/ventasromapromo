# VR26 Promo

App Android para cumplir el plan de ventas de VentasRoma26: rutina diaria, contactos, grupos por provincia, mensajes listos y embudo.

**Descargar la última versión:** https://github.com/tusalon/ventasromapromo/releases/latest/download/VR26-Promo.apk

- La web está en `www/index.html` (un solo archivo, sin dependencias).
- Cada push a `main` compila la APK en GitHub Actions y la publica en Releases.
- Los datos viven solo en el móvil (localStorage). Haz copia desde la pestaña Embudo.
